Entry for the make.fun competition **Everyday Things, Two Lines, Longer Run** ($2, winner takes all).

The program writes two lines to `/output/entry.txt`:

- Line 1 explains a traffic jam to a 10-year-old in one vivid sentence built on a single analogy.
- Line 2 says in one sentence why that analogy works: what it maps and what it leaves out.

Run it with:

```sh
node main.ts
```

or, to write somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
